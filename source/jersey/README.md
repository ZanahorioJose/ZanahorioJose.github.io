# ⚽ 球哥的足球账本

个人足球花销记录页，分「展示版」和「管理版」两个页面，共用同一份数据和图片素材。

## 两个版本

| 文件 | 用途 |
| --- | --- |
| `index.html` | 展示版：发布到网站用的，没有添加 / 编辑功能 |
| `admin.html` | 管理版：自己电脑上记账用的，可添加、编辑、删除、保存数据 |

## 文件结构

```
jersey/
├─ index.html       # 展示版（发布网站时上传）
├─ admin.html       # 管理版（仅本地使用，不上传）
├─ style.css        # 样式（两个版本共用）
├─ app.js           # 渲染脚本（两个版本共用）
├─ data.js          # 数据文件（两个版本共用）
├─ README.md
└─ assets/
   ├─ live/         # 现场看球照片（球场、票根等）
   │  └─ logos/     # 中超队徽（按赛季分文件夹：2023 / 2025 / 2026）
   └─ jersey/       # 球衣照片
      ├─ logos/     # 俱乐部 / 国家队队徽
      └─ *.jpg      # 球衣照片
```

## 怎么用

1. 平时用 `admin.html` 记账：添加 / 编辑 / 删除记录。
2. 改完后点顶部「保存到 data.js」生成最新数据文件（Chrome / Edge 可以直接覆盖原文件；其他浏览器会下载，手动覆盖即可）。
3. 发布网站时，只上传 `index.html`、`style.css`、`app.js`、`data.js` 和 `assets/` 文件夹，`admin.html` 不传，网站上就没有添加功能了。

## 图片怎么放

- 把图片放进对应文件夹
- 添加记录时在「图片」栏填相对路径，例如 `assets/jersey/italy_2026_away.jpg`
- 也可以直接上传图片，但上传的图片会以 base64 存进浏览器本地存储，大图容易超容量，建议照片类素材用路径方式

## 素材命名规范

**通用规则**：全部小写字母 + 数字 + 连字符/下划线，不含空格、中文、括号。

### 队徽（SVG，放在 `assets/live/logos` 或 `assets/jersey/logos`）

| 类型 | 命名格式 | 示例 |
| --- | --- | --- |
| 中超队徽（按赛季归档） | `assets/live/logos/{赛季}/{球队slug}-v{徽标年份}.svg` | `assets/live/logos/2025/shanghai-port-v2021.svg` |
| 俱乐部球衣队徽 | `{球队slug}-fc-v{徽标年份}.svg` | `chelsea-fc-v2026.svg` |
| 国家队球衣队徽 | `{国家slug}-national-team-v{徽标年份}.svg` | `germany-national-team-v2021.svg` |

`v{年份}` 是**徽标版本对应的年份**，而不是球衣购买年份。挂队徽时按球衣赛季匹配版本：

- 老赛季切尔西球衣（2024/25、2025/26）→ `chelsea-fc-v2006.svg`
- 未来 2026-27 赛季切尔西球衣 → `chelsea-fc-v2026.svg`（已入库，暂未挂载）

### 照片（JPG，放在 `assets/jersey` 或 `assets/live`）

| 类型 | 命名格式 | 示例 |
| --- | --- | --- |
| 球衣照片 | `{球队slug}_{赛季}_{主/客场}.jpg` | `italy_2026_away.jpg` |
| 现场比赛照片 | `{日期}_{主队slug}vs{客队slug}.jpg` | `2025-08-09_shenhua_vs_port.jpg` |

队徽用连字符（`-`），照片用下划线（`_`），便于一眼区分文件类型。

跨年赛季（如 2024/25）在文件名里用连字符代替斜杠：`chelsea_2024-25_home.jpg`。

## 数据备份

- 管理版顶部可「导出 JSON」/「导入 JSON」做备份与恢复
- 「恢复示例」会把数据重置回示例
- 页面有未保存的修改时会显示黄色提示条，记得保存到 data.js

## 记录类型与展示方式

| 类型 | 展示方式 |
| --- | --- |
| 现场看球 | 卡片墙（赛季筛选 + 按日期排列） |
| 球衣 | 分组卡片墙（俱乐部 / 国家队 + 赛季 / 版本 / 印号 / 号码 / 球员） |
