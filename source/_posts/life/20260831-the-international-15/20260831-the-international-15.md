一年一度的 Ti 大赛再度降临，这一年非常特殊，因为举办地在上海。

{% asset_img entrance.jpg 入场口大大的指示牌 %}

# CN DOTA

作为一个在家门口的比赛，我们的 CN DOTA 简直是拉完了。三个中国战队，去年的亚军 XG 直接被 1-4 淘汰，剩下的 VG 和 TR 则是在死亡之日双双出局。收购了前 Heroic 战队的 LGD，我们的洋枪队也在死亡之日的最后一场比赛里，被 Yandex 手撕，在小组赛最后一天最后一场遗憾地结束了这次短暂的征程。

{% asset_img mars.jpg %}

如同我赛前预料的一样，这三支队伍里面，成绩最差的应该是 XG（虽然我的作业仍然是相信 XG 能够 3-2 出线），去年的亚军燃尽了哥哥的一切，然后现在进入“三而竭”的状态。纵观过去一年以来中国战队的表现，我觉得没有新鲜血液的问题是最大的。纵使在 CN 预选过程中，有非常多新鲜的中国战队、青训队冒出来打打比赛，但是成绩上其实还是不如老人们的，所以其实中国区一直是老资历们在撑起电竞的大旗。至于现在这些老资历们组成的战队，可以说就是一个小池子在进行排列组合：大哥位是 Ame，Shiro，Lou；中单是 Xm，NTS，Emo；三号位是 Xxs，Bach，Niu；战队换来换去，人员就在这么些人里面来回挑。食材储备贫乏，米其林星级厨师来了都摇摇头。

我觉得中国赛区的境遇应该是和北美一样的，DOTA 这个游戏，北美赛区也没什么人，甚至几个中国留学生都能组建一支战队去参加预选赛。想想看未来如果中国和东南亚合并成一个赛区，可能我们连进小组赛的机会都没有了。

{% asset_img egis.jpg %}

# DEAD GAME

不说令人悲伤的 CN DOTA，来看看令人兴奋的最终总决赛吧。

{% asset_img wings.jpg 护国神翼已经是十年前的事情了吗？ %}

谁说 DOTA 是 Dead Game 的？我周日早上在东方体育中心门口，入场的观众摩肩接踵。除了国人之外，最多的就是来自独联体国家的大高个了——我生命中听到俄语浓度第二高的一天（第一高的当然是我去俄罗斯旅游的时候）。这是我第一次看电竞的现场比赛。以前我很纳闷大家在现场都在看什么，因为全程就是盯着一个大屏幕。不过自从我去现场看过一次球赛之后，我就明白有些东西一定要去了现场才能感受到：现场的声音、观众的情绪、不可见的氛围，这几样东西是转播画面永远无法传达的。我们来现场看的不只是比赛本身，还有选手的神情、观众的欢呼、震耳欲聋的音效。如果没有来现场体验过 Yatoro 丝血逃生/反杀时沸腾的声浪，我觉得你就没有体验到 DOTA 作为电子竞技游戏真正的魅力。

# THE FINAL

周日比赛的观众真的非常多，从检票入口走到会场入口都有非常多的活动。这次还来了一些俄罗斯/乌克兰的黄黑大V（还好我提前做了功课），听说她们本身就是 DOTA 爱好者，这次顺便也来上海曝个光。这是你才能体会到上海这座城市的开放和包容。

{% asset_img fox.jpg Sweetie Fox 的龙心撒旦莉娜 %}

说实话我还挺想要那个冰女的手办的。冰女、小黑、女王、风行四大美女至宝，要是有的话我都想入手。（我说的是游戏内皮肤）冰女的是我市场上随便买的，风行是之前宝瓶活动氪的。下一步就看小黑和女王什么时候返场了。虽然我远程炮台 C 只会玩火女，但是对于小黑来说，应该差不多吧，反正这些远程炮台都挺怕被近身的，谁不是站在远处点点点呢？现在的 DOTA 应该是可以凑一个全女至宝队的，我觉得最合理的阵容应该是：大哥小黑，中单**女王**，劣单军团，辅助风行与冰女。之所以是女王而不是火女，是因为火女至宝有一点捞，颜值不算特别高。而且女王还有一首魔晶沉默，救大哥有一手的。

{% asset_img qop.jpg %}

{% asset_img wr.jpg %}

丫丫的统治力真的很恐怖，他的一号位永远能够在意想不到的地方 Carry 全场，但是小孩也不是省油的灯。DOTA 是一个团队游戏，五个人里面有任何一个人掉队，都能够毁掉一场比赛。给今天的比赛做一个小总结的话，No\[o\]ne 带着 PV 挺进了第五把，而 Larl 则是拖着雪碧强行打到了第五把。还好丫丫和崩溃的实力更胜一筹，否则我觉得 Larl 要变成罪人了。

{% asset_img end.jpg %}
{% asset_img scene.jpg %}

今天的比赛是10点钟开始的（败决），雪碧最终夺冠已经是九点半，他们打了一共七场比赛。雪碧的粉丝要感谢 Yandex 实力确实一般般，2-0 就轻松拿下了，如果败决拖到了图三，很难说总决赛到了第三把第四把雪碧的决策会不会出问题。
{% asset_img screen.jpg %}

希望来年还能有更精彩的比赛。
