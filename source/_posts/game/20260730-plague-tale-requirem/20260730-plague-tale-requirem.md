最近周末在家疯狂肝，是把这款拖了非常久的单机作品给通关了。

# 游戏性
我是玩过这个游戏1代的，2代的很多机制都非常熟悉，但是我已经忘记了1代的交互了，所以不知道哪些东西是2代新增的。只是觉得这一代的投石索和罐子依旧强劲。我开的是普通难度，战斗上没有任何挑战，绝大多数敌人基本靠拉风筝就能够清理干净，而且敌人的反应速度是比较感人的。我有好几个场景都是瞎走，走着走着就杀完了人，就走到了下一个场景的门口。从游戏性上来说，二代的提升不是非常明显，如果想要玩进去，重点还是要放在剧情和画面上。

{% asset_img front.jpg 上来就是令人绝望的老鼠海 %}

# 画面

本作依旧保持着高水准的建模和光影，我开着大力水手和 2K 分辨率，很多时候离屏幕一远，就仿佛再看真人电影了。并且游戏的优化中规中矩，我能在 60-100 帧之间保持稳定，已经超过很多近几年新游戏的平均水准了。

{% asset_img night.jpg %}

更好玩的是，本作的老鼠也做了很多升级，万鼠同屏的场面非常多，有时候盯着几只老鼠发一会呆，它们的动线是很自然的。特别是老鼠遇火溶化的场景挺多的，作为第一代玩过来的，其实对于这些老鼠已经没有什么感觉了，因为我知道只要我靠近光，我就能活下来；但是我的敌人们就没有这么幸运了，因为我有灭熄剂。这个东西在这个游戏里相当的 bug，什么火都给你灭了。

{% asset_img rat.jpg 鼠潮 %}

# 剧情（含剧透，慎点）

接下来是我通关之后对剧情的相关感受，不想被剧透的可以不往下看了。

## 不死鸟

衔接上第一步的剧情，这一部里面德·卢恩一家人是想要尝试解开雨果身上的诅咒的。在整个游戏过程中，象征解药的双峰山和不死鸟占据了非常多雨果的梦境，主角一行人也希望最终能够找到这片湖，解开雨果身上的诅咒。

{% asset_img pheonix.jpg 不死鸟是雨果梦境中频繁出现的意象%}

虽然雨果的梦很美好，但是看过了预告片、玩过第一代之后，我深知这个意象最终会化作一个极度令人失望和颤栗的真相，往每个玩家心中插上一刀，不管结局是好是坏，在临近结局的时候，编剧肯定会给玩家发一把刀。这个是毋庸置疑的。因为我通关了《生化奇兵·无限》，我知道这种放在游戏开头的美好意象，一定是乌托邦式的，最终让主角带领着玩家一步步迈向深渊，迈向真实。但是我并不觉得这种情况下好结局一定优于坏结局；得知真相之后，做出的看似痛苦的决策，可能反而是最真实最让人释怀的。


## 伯爵

教会隐藏着鼠疫的秘密，红城也是：竞技场的另一端藏着瘟疫的可怕真相，藏着蔓延在贫民区的绝望。

{% asset_img pool.jpg 古代瘟疫必然意味着落后的医疗条件，这种令人不适的画面在游戏里看多了，也就习以为常了 %}

我觉得德·卢恩一家人始终在抗拒教会和朝廷，他们想要用自己的努力寻找答案。所以他们去找了被教会控制起来的福登学士。虽然对于阿米西娅来说福登在折磨自己的弟弟，但是我觉得游戏中福登学士象征的是想要解开真相的中立学者们（为什么我要在这里重点强调解开真相和中立，看过后面的剧情就懂了，我也会在后文陈述）。他们不想站边，只是想要了解这个世界运转的规律。只可惜时代没有给他们这个机会，让他们能够沉浸在象牙塔里面完成研究。福登之死也很意外，他不是被老鼠杀了，也不是被士兵杀害，是在鼠群爆发之后被房梁给砸死了。怎么说呢，他的突然下线有一些让人可惜，但是又能怎么办呢？这个世界上无力的小人物太多了。

来到岛屿上之后，伯爵夫妇不仅捉拿了阿诺德，还热情地请姐弟俩去堡垒里面居住。有句话说得好，“免费的就是最贵的”。我对公爵二人的好客没有怀疑，但是关键是姐弟二人是跟着阿诺德一起上岛的，阿诺德试图杀害公爵，但是公爵敌不过艾米莉的“善良”，还是收留了姐弟俩。

{% asset_img victor.jpg 公爵，他的长相总让我想到戴米恩·德·图尔，他在昆特牌里面的形象和这个太像了 %}

我玩到这里的时候会有一些疑惑，为什么艾米莉愿意接纳姐弟俩，仅仅是因为她想展示自己的乐善好施吗？玩到后面我其实明白了，艾米莉一直在找那个传说中的灵童，她想要成为灵童的母亲。而且在传说中灵童是有一位姐姐角色的保护人存在的，所以艾米莉会接纳这对姐弟，就是想知道他们是不是有可能是灵童在世。

{% asset_img emily.jpg 公爵夫人艾米莉很美丽，但是也仅仅是皮囊罢了 %}

虽然艾米莉的出发点是比较功利的，但是她身上也充满了悲情色彩。从小受家庭教育的影响，艾米莉受过伤，自己不能生育，长期的心态扭曲让她想要将灵童占为己有，所以甚至做了一个“华丽”的仪式，残忍歌喉了比阿特丽丝……这一段情节算是结尾处的一个次高潮，把玩家压抑的情绪通过雨果的视角释放出来。
- 为什么说是压抑的情绪呢？因为在这一段演出之前，阿米西娅刚刚被公爵偷袭，一路躲藏。操纵失去武器的阿米西娅就像是在玩《逃生》，患上了火力不足综合征。爽了一整场的阿米西娅突然变成了路人 NPC，对于之前就不善潜行的我来说操作难度直线升级，疯狂失败重开。
- 然后到了鼠潮爆发之后操作雨果疯狂杀士兵，就成为了一个很好的发泄窗口。

{% asset_img murder.jpg 献祭仪式 %}

## 阿米西娅

这一代的阿米西娅相较于上一代，成长了非常多。制作组在建模的时候也一定是做过许多优化的。现在游戏圈有一些 DEI 风潮，很多游戏角色都做了丑化/性少数化。但是其实我觉得这部游戏里的阿米西娅的选择是更加符合她的人设的：成熟、中性、冷酷。

- 因为我玩过《地平线·零之曙光》，我知道克洛伊经历了什么，她本身就是一个成年人，一代二代的差距理论上没有很大；但是《地平线·西之绝境》的建模显然被索尼的大手特调过，加入了太多抽象元素，反而让这个游戏在建模上遭受了太多诟病。
- 反而是《瘟疫传说·安魂曲》的改动，我觉得符合我对一个经历过和亲弟弟出生入死的未成年女孩的形象。如果说在一代开头阿米西娅还是一个懵懂的贵族少女，那么在二代，她就应该是一个战士，一个中性的形象能够衬托出她的冷静和责任感。


{% asset_img growup.jpg %}

更何况本作阿米西娅和女海盗索菲亚也结交了非常深厚的友谊。索菲亚更多应该是一个吉普赛形象，放在当年应该不算少数群体，只是欧洲语境下的外乡人罢了。阿米西娅和索菲亚之间的互动很精彩，从最开始的索菲亚换阿米西娅人情，到最后索菲亚愿意和阿米西娅一同战胜马库拉，这一段友情的递进自然而浓厚，我不会因此感到突兀。

{% asset_img sophia.jpg %}

{% asset_img sophia2.jpg %}

除了索菲亚之外，卢卡斯也是一个非常重要的角色，他是比阿特丽丝的炼金学徒，严格意义上来说不算家人，但是阿米西娅最后对着卢卡斯吐露心肠，这里除了对自己母亲学徒的亲近之外，我觉得肯定也蕴含了阿米西娅青春期的一些少女之心，毕竟在这个世道下，陪着自己的卢卡斯简直就是一个小天使。当然卢卡斯是有一些追求的，他在结尾也去云游四方，探索炼金的奥秘。

{% asset_img lucas.jpg 小卢卡斯的道具真好用 %}

## 雨果

小雨果别的不说，只想说一点和结局有关的。我觉得在游戏中段，雨果可能就意识到解决自己问题的方式就是面对死亡，他幼小的心灵已经承载不了自己带来的灾难。尤其是在见到初代携带者之后，也意识到即使深陷地牢，只要携带者还活着，鼠疫就能够冲上地面，给世界带来毁灭。

{% asset_img carrier.jpg %}

{% asset_img jail.jpg %}

我非常喜欢游戏结尾，阿米西娅和雨果重逢的那一部分，雨果通过自己的方式告诉阿米西娅，让她别再徒劳了。我在玩的时候很喜欢这种感觉：如果沿着游戏的指引往前走，会无限陷入死循环；此时如果掉头，就能逃出迷宫。如果要和虚构的怪物战斗，只会被它吃掉；但是熄灭身下的火堆，坦然面对黑暗和恐惧，雨果就会收手，带你走出迷雾，抵达最终的时刻。

而游戏的战斗结尾我可能一辈子不会忘记，因为是作为姐姐的玩家，在两代游戏之后，亲手了解自己弟弟的生命。游戏在这里做了艺术化处理：无论你的投石索技巧如何熟练，在这一刻的蓄力都显得如此缓慢，因为阿米西娅心中肯定是一万个不愿意，我相信也没有任何一个玩家会直接将石头投掷出去，肯定经历了一些犹豫后，果断松开扳机键……

{% asset_img end.jpg 这一刻的投掷显得无比漫长 %}

雨果的结局不一定是最好的，他最后沉睡在了高山之巅，这里有野花和飞鸟长久相伴，最好的风景一览无余。远在天上的小雨果将永远原理瘟疫和鼠群，享受永久的安宁。
